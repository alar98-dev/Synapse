# Synapse: Cognitive Learning Platform

## 1. Vision
Synapse is not just an LMS; it is a **Cognitive Learning Ecosystem**. It combines self-hosted automation (n8n, Docker, Local AI) with a revolutionary assessment system driven by LLMs.

## 2. Dynamic Architecture

### 2.1 Core LMS (Django + DRF)
- **Courses**: High-level knowledge containers.
- **Modules**: Logical units of a course.
- **Lessons**: Individual learning steps (Video, Text, Script, Assessment).
- **Materials**: Supporting files (ZIPs, PDFs, Notebooks).
- **Progress Tracking**: Granular tracking of content consumption and cognitive benchmarks.

### 2.2 Cognitive Assessment Engine (CAE)
The CAE moves beyond binary tests (true/false) into **Inference-based Evaluation**.
- **Orchestrator**: Manages the evaluation flow.
- **Playground**: Interactive interface (Chat, Socratic puzzles, Debug missions).
- **LLM Reasoning**: Evaluates mental models, not just strings.
- **Cognitive Profile**: A multi-dimensional map of student understanding.

## 3. Technical Implementation Plan

### Phase 1: LMS Foundation
1.  **Models Update**:
    - `Module`: Linked to `Course`.
    - `Lesson`: Linked to `Module` (Type: Video, Playbook, Assessment).
    - `Material`: Linked to `Lesson`.
    - `Enrollment`: Links `User` to `Course`.
    - `Progress`: Tracking lesson completion.

### Phase 2: Cognitive Assessment Engine (CAE)
1.  **New App: `cognition`**:
    - `AssessmentSession`: Tracks a specific interaction between a student and the LLM for a lesson.
    - `CognitiveEvent`: Logs raw interactions (student says X, LLM interprets as Y).
    - `CognitiveReport`: Final evaluation generated by the LLM after convergence.
2.  **LLM Integration**:
    - Using local LLMs (Ollama/Faster-Whisper/Local-GPT) or API-based reasoning.
    - **Prompt Engineering**: Socratic guides, error injectors, and mental model mappers.

### Phase 3: Infrastructure & Automation
1.  **Docker Orchestration**:
    - PostgreSQL for data.
    - Django for Backend/API.
    - Redis for task queuing (Celery).
    - n8n for media processing pipelines.
    - Local AI containers (Faster-Whisper, etc.).

## 4. Documentation of Innovations
- **Self-Hosted Mídia Factory**: Automated trimming, subtitling, and verticalization.
- **Socratic Assessment**: Conversations that probe depth rather than recall.
- **Evidence-Based Progress**: Unlocking content only when cognitive convergence is detected.
