Synapse UI elements scaffolds

This folder is the target root for generated element scaffolds.
Run `python3 scripts/generate_elements.py` to populate categorized element folders.

Each element will contain:

- `index.html` — simple static preview
- `styles.css` — base stylesheet
- `component.tsx` — React TSX placeholder component

When implementing, replace placeholders with real implementations and move shared styles to a design system.
